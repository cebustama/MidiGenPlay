# reference/cross-project/ALWTTT/

**STATUS: CROSS-PROJECT REFERENCE ONLY**  
**Do not update these docs as MidiGenPlay package authority.**

This folder preserves ALWTTT-specific or ALWTTT-leaning integration documentation so MidiGenPlay contributors can understand how a real consumer project uses the package.

## Primary-home rule

For ALWTTT-owned game/runtime behavior, the **primary authoritative home lives in ALWTTT docs**, not here.
This folder keeps preserved reference copies and package-context explanations only.

What belongs here:
- ALWTTT runtime bridge docs preserved for package context
- ALWTTT card/bundle integration docs preserved for package context
- ALWTTT usage of MidiGenPlay inputs and outputs

What does not belong here:
- package runtime truth
- package authoring truth
- active planning for package features unless the plan is genuinely package-scoped
- any second competing primary home for ALWTTT game-owned behavior

## Conflict rule

If a conflict exists between these docs and package SSoTs, package SSoTs win for package truth.
If a conflict exists between these docs and ALWTTT's governed runtime/integration docs for game-owned behavior, ALWTTT wins for the game-owned side.
