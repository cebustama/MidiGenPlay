# authoring/

This folder contains the authoritative authoring documentation for MidiGenPlay.

What belongs here:

- package-owned authoring assets,
- editor tool workflows,
- authoring-side data semantics,
- conversion between authoring representations and runtime-consumed data.

What does not belong here:

- gameplay meaning of cards in ALWTTT,
- planning,
- speculative research that does not describe current package truth.

If authoring docs conflict with cross-project docs, the authoring SSoT wins for package semantics.
